02 — BUILT WITH + INSPIRED BY

Standing on open work.

Built With

  • Archil Cloud Disks — Persistent disk + /mnt/archil mount. Infrastructure only: Lane A created the 20-table schema and the pipeline populated it.

03 — LIMITATIONS & NEXT IMPROVEMENTS

What we'd improve next.

Independent re-runs match the stored verdicts everywhere the code governs — the gaps below are where humans still decide, and where the next rubric revision should go.

  • No durability. A kept opening is never rechecked; later history (e.g. the P83 closure) never re-enters unless a person re-opens the case.
  • Allowlist trade-off. Unlisted domains drop even primary sources, so a verdict can rest on a retrospective instead of the best source ().
  • Negative promises. "Never do X again" forces proving an absence; the rubric has no absence handling ().
  • Framing disputes. Tiers measure source strength, not factual disagreement — agreed numbers with opposite framing punt to undecided ().
  • Ambiguity can't win. Rule 7 sits below Rules 3–5, so live wording disputes are settled by a recorded human reading ().
  • Re-opens are principles, not code. Corrections are append-only new rows, but the reasoning lives in notes, not in the rubric (, ).
