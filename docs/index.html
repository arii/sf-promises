How Commitments Are Verified

Civic leaders, city agencies, and local teams make bold public commitments in council chambers, press releases, and campaign launches. Without persistent tracking against primary municipal records, those commitments quietly evaporate or shift once the initial news cycle ends.

TEMPORAL RETRIEVAL

Keenable Discovery

Searches official municipal domains (sf.gov, flysfo.com, legistar) with strict time-box windows to find verbatim quotes and realization dates.

PROCESS ISOLATION

Adversarial Advocates

Two model workers run in separate OS processes: Sandbox A seeks affirming realization proof, Sandbox B seeks contradicting abandonment or delay.

0 MODEL CALLS

Arbitrator & Archil Ledger

Arbitrator code executes 7 deterministic checks against SHA-256 source hashes on persistent Archil storage. Models draft; only code signs verdicts.

Methodology & Verification Trade-offs

Deterministic code verifies every claim against stored evidence. The boundaries below represent real civic trade-offs where human governance and evidentiary thresholds apply:

  • No durability: A kept opening is recorded when achieved; subsequent operational changes (e.g. the Mid-Market Whole Foods closure, ) require subsequent intake and re-evaluation.
  • Allowlist trade-off: Strict municipal and official domain allowlisting prevents counterfeit evidence, but may exclude valid investigative journalism until verified in public records.
  • Negative promises: Promises phrased as "we will never do X" require proving an absence (), which requires conservative evidentiary standards.
  • Framing disputes: When both sides cite the same verified numbers but disagree on political framing (), the arbitrator designates the verdict as Undecided.
  • Ambiguity can't win: To prevent hallucinated evidence, candidate quotes must match the saved document byte-for-byte, rejecting loose paraphrases.
  • Re-opens are principles: No records or verdicts are ever silently deleted; corrections are appended as new ledger entries with complete timestamped provenance.
